# Tahniyat Fatima — Portfolio

A responsive personal portfolio website built with semantic HTML, CSS, and lightweight JavaScript. It includes an interactive keyboard, project and about dialogs, a looping marquee, and contact links.

## Run locally

1. Save `index.html` and `README.md` in the same folder.
2. Open `index.html` in a modern browser.

No build tools or dependencies are required. The Google Fonts stylesheet is optional; the site uses system-font fallbacks if it cannot load.

## Configure the email address

The email address is `tahniyatfatima15@gmail.com`. Update the `email` constant near the bottom of `index.html` if you want to change it. The contact links are set to use that configured address.
